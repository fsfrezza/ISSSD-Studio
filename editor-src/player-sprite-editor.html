Editor de quadros

16 tipos (0–15). Cada cabelo de sobreposição possui 24 quadros. O tipo 0 está desenhado no corpo. Editar um desenho altera todos os jogadores que o utilizam.

Aplicar guarda os desenhos no projeto em edição. Use Salvar projeto para gravar o arquivo e Salvar ROM para exportar na fase Jogadores. As poses sem montagem confirmada aparecem como tiles de 8 × 8; o espaço vazio após o último tile não é editável.
