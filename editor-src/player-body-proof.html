Composição do jogador — prova de um quadro

Edite a cabeça diretamente no jogador montado. O corpo abaixo da cabeça fica protegido. Escolha a cor e clique ou arraste; índice 0 apaga. O desenho é substituído por inteiro, incluindo a transparência.

Original

Este HTML é uma ferramenta experimental local. Baixar o JSON guarda a edição; para gerar outra ROM, execute npm run body:proof -- --rom "ROM.sfc" --heads "cabecas.json". Somente o primeiro quadro de corrida de costas recebe a cabeça composta. Esta prova histórica usa somente um quadro. A exportação normal usa a base careca em todas as poses mapeadas.
