Aparência do jogador

Escolha o cabelo e uma das duas paletas disponíveis para este jogador. Os desenhos e as cores abaixo são lidos da ROM Plus carregada.

Tipos de cabelo

0 · Careca — 14 · Cabelo original — 15 · Cascão (Ronaldo). O tipo 14 preserva o visual original sem consumir sobreposições. Até três titulares podem usar os outros cabelos especiais. As novas versões precisam de conferência visual no emulador.

Pele e cor do cabelo

Paleta 0: jogadores
Paleta 1: jogadores

Prévia dos quadros nativos

0 é a base careca. 1–13 usam as sobreposições nativas; 14 recupera o cabelo original e 15 é Cascão.

O mesmo cabelo tem quadros diferentes conforme a pose e o movimento. Estas prévias mostram os pequenos gráficos nativos; as cenas aproximadas usam outros gráficos.

Copiar ou trocar com outro jogador

As operações aplicam imediatamente os atributos já confirmados dos jogadores: tipo de cabelo e índice de paleta (0/1). Escolhas ainda não aplicadas nesta janela não entram na operação. Entre equipes diferentes, as cores podem mudar: cada equipe mantém suas próprias paletas. A aparência dos goleiros é editada exclusivamente na aba Goleiros.

Outros tons de pele existentes na ROM — referência

Estas quatro paletas são referências nativas. Cada equipe define qual delas usa na paleta 1; elas não são quatro escolhas independentes por jogador. A paleta 0 também possui os tons próprios da equipe.
